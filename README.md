# FreeIA

Chat de IA gratis (PWA) con todos los modelos gratuitos: Pollinations (sin clave) y OpenRouter `:free` (clave gratuita en Ajustes).
Incluye modo Escribir/Investigar, generación de imágenes, adjuntos de texto, comparación de hasta 3 modelos e historial local.

Publicación: GitHub Pages → Settings → Pages → Deploy from a branch → `main` / root.
Para actualizar: subir la versión en `version.json`, `APP_VERSION` (js/app.js) y `CACHE` (sw.js).
